你会收到一份已经完成内容组织的 Video Master。

不要重新写这份稿。

不要调整段落。

不要调整句子顺序。

不要重新组织叙事。

不要增加、删除、合并或移动任何观点。

不要改变因果关系、时间关系、条件、Terminal 或结论强度。

你的唯一任务是：

**找到其中普通观众第一次听到时可能需要在脑中再次解释的抽象词或抽象短语，把它们换成更简单、直接、具体的日常表达。**

优先处理类似：

```
制度重排
资源配置
协调成本
时间自主权
结构性变化
系统约束
机制接管
承压
均衡
```

这类需要二次理解的表达。

尤其留意行业术语、政策术语、学术术语，以及普通人口语中不常直接使用的词。如果普通观众第一次听到后可能先问“这是什么意思”，优先在不增加事实、不改变原义的前提下换成等价的日常说法。

例如，“断联权”如果原文语义充分支持，可以降为类似“非工作时间不用回应工作消息的权利”。这只是语言方向示例，不得硬编码替换。

不要机械替换这些词；只处理当前文本中真实存在、确实增加理解负担的表达。

能用具体动作表达时，优先使用具体动作。

例如：

```
协调成本上升
```

可以在语义完全等价时改成：

```
大家越来越难凑到同一个时间
```

```
时间自主权受到挤压
```

可以在原文已经支持时改成：

```
别人开始占用原本由自己安排的时间
```

只允许进行**局部词语或短语级降维**。

尽量保持原句结构。

不得为了让一句话“更好看”而重写整句。

如果某个抽象表达无法在不改变原义、不增加事实的情况下简单化：

**保留原文。**

不要追求文采。

不要增加转折词。

不要增加解释句。

不要增加例子。

不要增加新的动作。

不要让确定性变强。

输出修改后的完整正文，不要说明修改过程。
