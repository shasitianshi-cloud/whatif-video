# 推演源

## 反事实契约

从当前时刻起，太阳永久停止向外持续发出太阳风。已经离开太阳的太阳风不会凭空消失，而是继续向外传播；太阳光、其他电磁辐射、太阳质量与引力、行星轨道和物理规律维持基线。本契约只移除持续背景太阳风，不自动删除所有偶发日冕物质抛射，也不增加爆炸、额外能量或替代粒子流。

## 传播延迟与地球附近

太阳风不是光，太阳停止继续发出太阳风以后，地球附近不会在同一秒发生变化。已经在太阳与地球之间传播的等离子体仍会先经过地球，因此主要变化要在最后一批背景太阳风到达并离开之后才逐渐显现。精确时刻取决于当时太阳风速度，可靠结论是存在传播延迟，而不是瞬时切换。

背景太阳风持续给地球磁层施加动压并携带行星际磁场，与磁层交换能量。背景太阳风消失后，这种持续压迫和能量输入会大幅下降，磁层会向新的外部压力条件调整。由普通太阳风高速流和持续磁场条件造成的大量日常空间天气活动会减少，常态极光活动也会明显变弱。

## 仍然存在的太阳爆发

‘持续太阳风停止’不等于‘太阳所有爆发活动都停止’。如果日冕物质抛射等偶发等离子体事件仍按基线存在，它们依然可能抵达地球并短时扰动磁层。因此不能把终态写成‘从此绝无地磁暴或极光’。更准确的状态是：持续背景驱动消失，日常空间天气明显安静，但偶发太阳爆发仍可能带来事件。

## 日球层与宇宙线

太阳风向整个太阳系持续输送磁化等离子体，并与星际介质共同塑造日球层。停止补充太阳风以后，现有日球层不会瞬间消失；已经存在的等离子体和磁场还会继续演化，外部星际介质随后推动边界重新调整。这个过程跨越的空间极大，精确收缩速度和最终边界需要完整等离子体模型，不能从单一反事实直接给出固定时间或距离。

太阳风和它携带的磁场会调制进入太阳系的银河宇宙线。随着日球层持续太阳风环境逐步减弱，这层调制会减弱，更多银河宇宙线能够进入内太阳系。变化首先改变的是行星际和深空辐射环境，而不是把地球表面立即变成致命辐射区。

## 地球屏障与航天活动

地球自身的磁场和厚重大气仍然存在，它们继续屏蔽和吸收大量高能粒子，所以地表不会因为太阳风停止就在几天内出现统一的辐射灾难。更直接的长期压力落在深空航天器、月球或火星航行、载人深空任务以及对高能粒子敏感的电子设备上。随着银河宇宙线调制减弱，任务需要重新评估屏蔽、累计剂量、器件容错和工作时长。

## 其他可见变化

彗星的离子尾和等离子体环境会受到太阳风影响。持续太阳风消失后，离子尾的结构和与太阳风有关的扰动会改变，但太阳光仍在，因此由太阳辐射加热产生的尘埃活动和尘埃尾不会因为这个契约自动消失。这个例子说明，太阳风停止改变的是太阳系的等离子体环境，不是把所有由太阳造成的现象一起删除。

## 时间尺度与不确定性

数天量级首先体现为太阳风传播延迟后的地球磁层输入变化；随后空间天气平均状态和极光背景发生变化。更长时间里，日球层边界和银河宇宙线分布逐步重新平衡。这里不存在一个能可靠描述所有后果的单一阈值，因为磁层、日球层和宇宙线的响应发生在不同尺度，并且偶发太阳爆发仍是重要竞争机制。

## Terminal State

终态不是一个失去太阳影响的太阳系。太阳仍照亮并引力束缚各行星，地球仍有磁场和大气，但太阳系失去持续太阳风这股遍布行星际空间的背景粒子流。地球附近的日常空间天气整体更安静，常态极光减少；与此同时，日球层长期缩小并重新平衡，对银河宇宙线的调制减弱，使深空辐射环境比现实基线更严苛。偶发太阳爆发若仍存在，仍可能短时打破这种安静状态。
